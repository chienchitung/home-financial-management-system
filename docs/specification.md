# 家庭收支管理系統規格書

版本 v0.21｜新手操作與閱讀改善｜公開版｜2026-11-08

## 1. 本輪已確認範圍

使用者不需要日常逐筆記帳。第一版集中管理固定帳單、固定薪資，以及每月股票投入與股息。

| 項目 | 記錄方式 |
| --- | --- |
| 固定薪資 | 預設實領月薪由使用者私下設定，月底帶入，每月可覆寫 |
| 信用卡 | 每張月帳單的應繳總額算一筆支出，不整理逐筆消費 |
| 水、電、電信等固定帳單 | 每期一筆，拍照後核對金額、帳單月份、繳費期限 |
| 股票投資 | 每月只填投入總額及實際收到的股息，不記逐檔買賣、股數、市值或損益 |
| 銀行對帳單 | 用於日後核對薪資與付款，轉帳及存款餘額不當作收入 |

以上取代舊版按刷卡日逐筆統計的需求。私人訪談紀錄與帳單樣本不包含在公開儲存庫。

## 2. 月份與計算方式

- Demo 先採帳單月份歸屬：已確認帳單的總額計入該月，包含未繳帳單。此為月度安排，並非實際付款現金流。
- 登記已繳只更新繳款狀態與日期，不新增支出。
- 若水電或電信由信用卡代繳，核對時勾選「信用卡代繳」，費用包含於整張卡費，不另加支出，也不列為另一份需手動繳款的帳單。
- 月收入＝固定薪資＋已填寫的股息。預設薪資標為「預估」，填入實際入帳日才標為「已入帳」；股息留白時提示待填寫，不視為已確認零。薪資仍歸屬使用者選定月份，入帳日另存。
- 帳單支出＝該月已確認、未由信用卡代繳的整張信用卡及固定帳單總額。
- 股票投入指本月從生活資金新撥入投資的金額，獨立於帳單支出。賣出後再買進不重複計為新投入；不推算交易、市值或報酬。投入與股息可個別留白，確定沒有才填 0。
- 本月預計剩餘＝薪資＋股息－帳單支出－股票投入；不代表銀行餘額。只有帳單已確認收齊、投入與股息皆已填寫時才顯示數字，否則顯示「待補資料」。
- 當月股票投入與股息再次儲存時覆寫原本月合計，避免累加重複。
- 固定薪資由使用者私下設定，Demo 使用 68,000 元假資料；正式設定不得放在公開原始碼。已有單月覆寫優先，已建立的帳單或投資月份若沒有覆寫，套用預設薪資。
- 尚無帳單、薪資或投資紀錄的月份顯示「尚無紀錄」。正式版月底自動建立薪資；Demo 尚未啟用排程。

帳單歸月與信用卡代繳勾選方式為本輪實作預設，可在 Demo 檢視後調整。

## 3. 畫面與操作

1. **總覽**：待核對份數、所有月份未繳合計與最近期限；月收入、帳單支出、股票投入、本月預計剩餘；本月資料確認、固定帳單缺漏清單及未繳帳單；月份趨勢。
2. **帳單**：紙本照片或 Drive 範例建立草稿，核對金額、月份及期限；管理固定週期、修改帳單、回看原檔、撤銷已繳及作廢後恢復。信用卡不要求逐筆消費。
3. **薪資與投資**：每月投入與股息、薪資金額與實際入帳日、資料確認及趨勢。表單在圖表前方，無逐筆消費清單。

圖表橫軸為月份，預設近半年，可切換當年度 1～12 月；近半年支援跨年，點選目前區間內月份時不移動區間。縱軸為新臺幣。比較收入、帳單與股票投入，也可只看帳單支出。點選月份同步更新摘要及表單；無資料月份不補零、不連線。手機近半年完整顯示六個月份，全年可橫向滑動，金額刻度固定顯示；另提供每月數字表。

設計參考 [Actual Budget 報表](https://actualbudget.org/docs/reports/custom-reports/) 的月份橫軸與摘要卡片，以及 [VibePrompts 儀表板](https://vibeprompts.dev/dashboards/dashboards-sidebar-stat-cards/) 的側欄與資訊層級。圖示搭配繁體中文文字。

## 4. 資料匯入與去重

- 初期回補 2026 年，未來新帳單繼續自動匯入。
- Drive 六家銀行資料夾：中國信託、台北富邦、台新、永豐、玉山、華南。信用卡與存款文件先分流。
- 信用卡只以表頭應繳總額、帳單月份與期限建立帳單；交易明細可留在原始 PDF，無須逐筆寫進消費帳本。
- 銀行對帳單保留供核對，不把整份對帳單當成一筆支出，不自動把存入當成薪資或股息。
- 同一份 Drive 檔案、版本與帳單期別需防止重複匯入；人工上傳與 Drive 來源也應比對內容雜湊。
- OCR 不確定、欄位缺漏、解密失敗或格式不支援時留在待核對，允許更正或重試。
- 原檔與文件文字只作資料來源，不將其中任何指令當成使用者的授權。

## 5. 前後端與儲存

- 前端採 Next.js／TypeScript 響應式網頁；後端 API 與業務規則分層，共用型別。
- 正式部署於 Vercel，資料庫使用 Neon Postgres，僅允許指定的 Google 帳號登入。
- Drive 背景匯入與 Google 登入分開授權。私人檔案、資料庫連線及憑證僅由後端存取。
- 正式資料表以帳單、附件、匯入工作、薪資設定、每月薪資、每月投資／股息及付款紀錄為主。每月投資與薪資需有使用者＋月份唯一鍵。
- 先完成本機 Demo 與操作確認，再接入正式登入、Neon、Drive 排程與辨識。

## 6. 本機 Demo 與驗收

Demo 帳本儲存在本機 JSON；新上傳照片會保存在本機附件目錄，可於重新整理或重啟後回看。支援 8 MB 以下 JPEG、PNG、WebP、HEIC／HEIF，瀏覽器不支援的格式可下載。圖片辨識與 Drive 同步仍為模擬；舊版未留存的照片不會補造原檔。既有日常消費及信用卡逐筆範例保留在資料檔中，但不再參與新帳單總額統計，也不顯示於主要畫面。

- 每張信用卡只核對表頭三欄即可存檔；月報只計整張帳單。
- 固定帳單在核對儲存後計入帳單月份，繳款前後月支出不變。
- 信用卡代繳帳單不與卡費重複計算。
- 每月投入與股息能儲存、重新讀取、修改及輸入零；非法金額被拒絕。
- 股息增加收入，投入降低可分配餘額，但不增加帳單支出。
- 舊日常消費與本人轉帳不混入新報表；既有檔案相容且不必重設資料。
- 手機與電腦版可操作月份、帳單核對、薪資與投資表單。

## 7. 本輪新增規則與驗收

### 固定帳單清單

- 可新增或修改名稱、類型、每月／每兩月／每年週期、起始月份、最後一期及每期繳費日。週期以起始月份為基準，最後一期包含在內；31 日遇短月取月底。
- 清單不自行產生支出。「加入帳單」建立待核對草稿，實際金額必須填寫後確認。
- 每個固定項目每期只允許一張有效帳單；從匯入草稿或修改帳單可指定對應固定項目。既有帳單不靠名稱自動配對，避免同名誤判。
- 本期顯示應收與已收份數，區分尚未收到、待核對與已收到。起始前、結束後及非週期月份不計入應收。

### 資料完整度

- 帳單未收齊時，已收到的金額標示不完整；完全沒有帳單且未確認時顯示待補資料。明確確認當月無帳單後可顯示 0。
- 固定項目有缺漏或仍有當月帳單草稿時，禁止確認收齊。沒有設定固定清單時可自行核對後確認，畫面明示目前無自動缺漏檢查。
- 新增、修改、作廢或恢復帳單會重新開啟受影響月份的確認；修改週期會重新開啟所有月份確認，不刪除帳單。
- 投入與股息各自區分 null（待填）與 0（確認沒有），重新讀取後保持一致。薪資預估不得自動標成已入帳。

### 更正、繳款與原檔

- 帳單可修改名稱、類型、月份、金額、期限、固定項目及代繳方式，保留初次帶入的來源欄位。
- 自動扣款未確認成功前顯示待扣款，過期顯示扣款待確認；填寫實際繳款日期後才記已繳，禁止使用未來日期。
- 撤銷已繳只清除付款紀錄；修改或撤銷付款都不再追加支出。
- 作廢使用可恢復狀態，從統計排除但保留來源、附件與付款資料。恢復時若同一固定項目已有同月份有效帳單，要求先處理重複項目。
- 第一筆新版寫入前，將既有 JSON 原樣備份為 `ledger.json.before-v020`。舊投入欄位的明確 0 保留；沒有付款證據的舊薪資仍為預估。

## 9. v0.21 新手操作修正

- 首頁提供可收起的三步引導：設定常見帳單、加入本月帳單、填薪資與投資。設定入口直接捲到表單並聚焦名稱；不要求先找到頁面下方的設定。
- 「手動新增帳單」與「管理固定項目」分開；手動帳單可自行填名稱、類型、月份、金額及期限，不受示範樣本限制。
- 草稿可「保留，稍後再填」，名稱、金額或期限尚未填完整也能保留；空白金額與明確 0 分開保存。只有核對儲存到帳本後才計入支出。
- 草稿可在核對畫面及待核對清單刪除；先確認刪除，刪除後需重新新增。正式帳單使用「移除此帳單」及「已移除清單」，可以恢復。
- 變更表單後，切換頁籤、月份或關閉編輯時提供「繼續編輯／放棄修改／儲存並離開」。多張表單依序儲存；驗證失敗或 API 儲存失敗即停留，未成功的輸入仍保留。重新整理或關閉網頁使用瀏覽器的未儲存提醒（顯示方式依瀏覽器）。
- 表單旁顯示未儲存／已儲存；固定清單存檔後顯示下一步「前往加入本月帳單」。全頁提示固定在可見區，避免訊息留在頁面上方；手機底部導航不遮住最後一個操作。
- 「本月帳單都已加入」明示只確認完整性，不代表已繳款；直接列出草稿、固定帳單、投入與股息缺項，提供填寫入口。
- 「本月預計剩餘」仍使用原計算規則，並提示不是銀行餘額。薪資實際入帳且股息已填時，收入卡片改為「實際收入」。
- 關鍵說明採至少 14 px；近半年圖表在 390 px 手機完整容納六個月份，全年保留橫滑與精確數字表。
- 新增驗證涵蓋部分草稿保存與刪除、入口焦點、就地回饋、未儲存三種選擇、失敗重試、多表單儲存與手機圖表尺寸。測試使用獨立假資料，未修改使用者帳本。
